# 北京大事件操作台 · Windows 离线包使用说明

## 30 秒上手
1. 把 `beijing-events-console-Offline-Windows-x64-<版本>.zip` 解压到任意目录（推荐 `%LOCALAPPDATA%\Programs\beijing-events-console`）。
2. 双击 `安装.cmd`（自动选端口 + 写配置 + 创建开机启动项）。
3. 双击 `run.cmd` 启动，浏览器打开 `http://localhost:<端口>`（安装时显示的端口）。
4. 用 `admin` / `change-me` 登录，进设置页改密码。

> 免管理员、免预装 Python/Node。首次运行需出站网络下载 Chromium（~150MB，一次性，之后离线）；运行时需访问 DeepSeek/Ark API + `zwfw.mct.gov.cn`（LLM + 演唱会采集）。

## 文件清单（解压后）
- `安装.cmd` — 首次安装入口（选端口 + 配置 + 启动项）
- `run.cmd` — 启动操作台
- `python\` — 内置便携 Python 3.12 + 全部依赖（已解压进 site-packages）
- `browsers\chromium-1223\` — Chromium（首次运行自动下载，演唱会采集用）
- `app\` — 后端代码 + `frontend\dist`（前端）+ pipeline 脚本 + canonical 数据
- `deployment\` — init_install.py / start_server.py（安装与启动逻辑）
- `config\service.json` — 端口 + 版本配置
- `config\users.json` — 账号（首次启动后端自动创建，gitignored）
- `config\llm_keys.json` — LLM Key（设置页配置，gitignored）
- `data\` — 运行数据（runs / canonical 备份 / 上传 / 发布 / console.db）
- `MANIFEST.json` — 产品/版本/运行时/构建时间

## 输入数据要求
- canonical Excel：首次携带在 `app\01_event_list_output\Events List.xlsx`；升级时 `data\` 保留，不覆盖。
- 初始数据（v1.0.1 起可选）：带初始数据的包里 `app\02_web_output\` 与 `app\data\` 非空（历史日历成品 + 运行记录），首启即可见；升级到已有安装时，先备份再操作，服务器上已有的 `data\` 与 `config\` 优先。
- LLM Key：启动后在设置页填 DeepSeek + Ark（或复制现有 `config\llm_keys.json`）。
- `.env`：**不需要**（Key 走 `config\llm_keys.json`，不碰 .env）。

## 运行步骤

### Windows（部署目标）
| 步骤 | 操作 |
|---|---|
| 安装 | 解压 zip -> 双击 `安装.cmd` |
| 启动 | 双击 `run.cmd`（或重启，启动项自动运行） |
| 访问 | `http://localhost:<端口>` 或 `http://本机IP:<端口>`（局域网） |
| 停止 | 关闭 run.cmd 窗口（Ctrl+C） |
| 升级 | 解压新 zip 覆盖程序文件，`config\` + `data\` 保留（不跑 安装.cmd 即可；首次升级可跑 安装.cmd，端口保留） |

### Mac（仅构建用，不部署）
```bash
# 1. 构建前端
cd frontend && npm run build && cd ..
# 2. 打包（下载便携 Python + wheels + Chromium，约 15-30 分钟）
.venv/bin/python deployment/build_release.py
# 产物：release/beijing-events-console-Offline-Windows-x64-<版本>.zip + .sha256
```

## 常见问题
- **双击 run.cmd 闪退**：看 run.cmd 窗口报错；常见是端口被占（改 `config\service.json` 的 port）或 `python\python.exe` 缺失（包损坏，重新解压）。
- **演唱会采集失败**：确认服务器出站能访问 `zwfw.mct.gov.cn`；Chromium 首次运行自动下载到 `browsers\`（需出站网络），`PLAYWRIGHT_BROWSERS_PATH` 由 start_server.py 自动设。
- **端口冲突**：编辑 `config\service.json` 的 `port`（10000-29999），或在包根目录跑 `python\python.exe scripts\audit_windows_ports.py` 选空闲端口。
- **忘记密码**：删 `config\users.json`，重启后端自动重建默认账号（admin/operator, change-me）。
- **局域网访问不了**：Windows 防火墙放行该端口（首次会弹窗允许）。

## 已知限制
- v1 单用户（一次一人操作），不引入 Redis。
- 对外日历推送走手动 zip 上传到项目管理平台（v2 才考虑自动上传 API）。
- 不支持删除账号（避免误删管理员；要删手改 `config\users.json`）。
- `.ps1` 数量为 0（IT 管控要求）。
